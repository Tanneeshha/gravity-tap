# Gravity Tap
### By Taneesha

## 📦 Project Overview
**Gravity Tap** is a hyper-casual, physics-based tap game where players must drop balls onto a balanced plank without tipping it over. Simple controls, minimalist visuals, and satisfying feedback make it quick to play but challenging to master.


## 🧰 Requirements

- Unity Hub (Version 2021.3 or later recommended)
- Unity Editor installed (2021.3 LTS or higher)
- Windows/macOS system
- Keyboard + Mouse or touchpad


## 🚀 Setup Instructions

1. **Download or Clone the Project**
   - Download the prototype folder from the provided Google Drive link.
   - OR clone from GitHub (if hosted).

2. **Open in Unity Hub**
   - Launch Unity Hub
   - Click on **‘Open’** and select the downloaded folder
   - Unity will load the project. This might take a minute.

3. **Install TextMeshPro (if prompted)**
   - Unity may ask you to import TMP essentials.
   - Click **‘Import TMP Essentials’** when prompted.

4. **Open the Scene**
   - Navigate to: `Assets/Scenes/MainScene.unity`
   - Double-click to open the main gameplay scene.

5. **Play the Game**
   - Click the **‘Play’** button in Unity Editor
   - Tap (or left-click) to drop balls and keep the plank balanced
   - Score as high as possible before tipping over


## 🎮 Controls

- **Tap or Left Mouse Click**: Drop a ball from the top center
- **Avoid overloading one side of the plank!**
- **Click Restart Button** when the game ends to try again
